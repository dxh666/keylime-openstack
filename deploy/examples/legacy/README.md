# Legacy Examples

This directory keeps historical, host-specific scripts that are useful for
reading old lab records but should not be used as current operational entry
points.

- `keylime-reactivate-csri9.sh`: old csri9-only verifier reactivation helper.
- `restart-keylime-agent-csri9.sh`: old csri9-only agent restart helper.

Use the parameterized scripts in `deploy/scripts/` for current operations.
